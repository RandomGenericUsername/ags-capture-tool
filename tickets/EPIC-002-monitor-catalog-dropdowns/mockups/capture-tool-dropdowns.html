capture-bar · interaction proposal · 2026-11-04

One field. One value. The alternatives only when you ask.

Replace the wall of side-by-side pills with a strip of compact field triggers. Each one names the setting, shows the active choice, and opens a small popover with the rest. The recording lane drops from 1506 px to roughly 780 px without losing a single capability.

@surface @on_surface @primary · selection @error → --rec-accent

The bar becomes a status strip first and an editor second. You can read every active choice at a glance; editing is one click deep, one field at a time. Recording keeps its red identity — but red moves into the bar’s structure, not into every selected value.

First run is not empty. Sane defaults are code constants — screenshot: Region, None, PNG, Clipboard, Cursor Off; recording: Region, 60 fps, MP4, High, System, ∞, Cursor On; GIF: 15 fps, Original. After the first change, the UI-state JSON is the source of truth. This panel is not a defaults screen.

The panel keeps only what the bar cannot express: file locations, notification behaviour, the compact indicator, placement and recording-controls ownership, plus the read-only runtime facts. Bar position and Recording controls stay segmented on purpose: in a form, showing all choices is faster; the dropdown is a density adaptation for the one-row bar, not a brand rule. Top offset dims when Bottom is selected so the dependency is visible without a layout jump. Compact bar indicator turns off and disables while On hover is selected, matching the v0.3.x policy that hover must expose Pause/Stop in one click. GTK Enter now reads “done” because every edit already persists; the footer keeps Esc and the Back button, so returning to the bar is always one action.

Keyboard contract

one ladder, four rungs
ContextEnterEsc↑ / ↓SpaceTab
Bar · nothing focused Commit capture Back one level — — Focus first field
Field focused · closed Commit capture Back one level — Open field Next field
Popover open Choose highlighted Close popover Move highlight Choose highlighted Close + next field
Custom editor Set seconds Cancel + restore Spin value — Move to Set
Enter never opens a field. This is deliberate: the documented contract is Enter = commit. Space and ↓ open. The one cost is that Enter does not activate a focused trigger like a native button; the CTA’s Enter chip keeps the promise visible.
Esc is a ladder: close the popover → clear the pending pick → close the lane → hide the bar. One key, four rungs; the overlay and the bar never disagree about which rung they are on.
Focus order: back → lane tabs → fields, left to right → CTA. Conditional fields are skipped because they are not in the tree. The popover traps arrows, not Tab.
After a choice: focus returns to the trigger. You can Tab to the next field or press Enter to commit immediately — the trigger never swallows the capture key.

11

Port notes & risks

GTK is not the browser

Widget shape

  • Gtk.MenuButton per field, custom child; Gtk.Popover + Gtk.ListBox rows. ListBox supplies ↑/↓/Enter; the window controller supplies the bar’s Enter contract.
  • The popover is a separate Gdk.Popup surface. Opening it must not call syncWindowSize(); changing Target or GIF must.
  • position = TOP for a bottom bar, BOTTOM for a top bar; let GTK clamp horizontally. Test both screen edges and 720p.
  • Use symbolic icons where possible so a palette refresh recolors them without rebuilding the popover.

Deliberate departures

  • No backdrop-filter: the translucency comes from the compositor; the bar plate is an alpha surface.
  • No solid-fill “selected” pills: selected is a tint + radio. This is what allows the red tally to carry the recording identity.
  • The bar’s shadow is clipped by the layer surface (existing note); the popover has its own surface, so its shadow is separate. Verify it is not clipped either; fall back to border-only if it is.
  • Labels are readable words now: System not Sys, Medium not Med. Keep one vocabulary in code and tests.

Monitor catalog

  • dotfiles-runtime monitors list --format json is the shared, language-agnostic service. The capture tool reads it through a MonitorCatalog port; future wallpaper-by-monitor tools use the same command.
  • The GDK topology stays authoritative for what can actually be targeted; the catalog enriches labels, geometry and the focused marker, and the two are joined by connector.
  • Read when the Monitor popover opens and refresh on the existing GDK topology change. If the runtime is unavailable, fall back to the GDK descriptors.
  • No cycle button: the popover lists every connected, enabled, non-mirrored output; choosing one calls the existing selection.selectMonitor(connector).
